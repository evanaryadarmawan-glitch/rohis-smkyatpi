Status Sinkronisasi Data

Perhatikan badge kecil di pojok kanan atas: "Tersinkron" (hijau) berarti seluruh data (kegiatan, pengurus, pembina, jurnal, aspirasi, kata sandi admin) sudah tersambung ke cloud (Firebase Firestore) dan otomatis sinkron secara realtime ke semua perangkat/browser yang membuka situs ini — perubahan dari admin panel manapun langsung tampil di semua perangkat lain tanpa refresh manual.

Jika badge menunjukkan "Mode Lokal" (abu-abu), berarti konfigurasi cloud belum diisi di assets/js/firebase-config.js, sehingga data hanya tersimpan per-perangkat (localStorage) seperti versi lama. Panduan lengkap pengaturannya ada di file SINKRONISASI-DATA.md pada folder utama proyek.

Perlu diketahui: sistem proteksi kata sandi admin ini tetap bersifat sederhana (client-side), bukan otentikasi tingkat server.
